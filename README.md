# Generador de paletas de colores

Herramienta web simple que permite generar paletas de colores de forma rápida e intuitiva.

## La aplicación funciona de la siguiente manera:

- Permite seleccionar el tamaño de la paleta (6, 8 o 9 colores).
- Puedes generar colores aleatorios en dos formatos: HSL y HEX/RGBA (elegir uno de estos últimos).
- Tambien tiene la opción de visualizar cada color junto a su código en el formato elegido (HEX o RGBA)

## Cómo usar:

El botón "Generar Paleta" funciona para crear las paletas con el tamaño y formato seleccionado.
Tambien como función rápida, puedes utilizar la barra espaciadora del teclado, que cumple la misma función.


## Adicional:

- Se puede copiar el código del color generado, para utilizarlo en lo que necesites
